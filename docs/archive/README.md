# docs/archive/

Historical or superseded documents kept for reference. Nothing here is the current source of truth.

If a doc lives here, that means one of:

- it was a **point-in-time audit** whose data has drifted (e.g. dated inventory reports);
- it was a **seed prompt** that bootstrapped a system, since superseded by living docs;
- it was a **runbook for a workflow that no longer exists** in its documented form.

Current canonical docs:

- `AGENTS.md` (repo root) — repo guidance for AI agents and contributors
- `plans.md` (repo root) — living execution plan + validation ladder + decision rule
- `README.md` (repo root) — what the project is and how to run it
- `docs/architecture.md` — subsystem-by-subsystem architecture
- `docs/system_spec.md` — ID'd requirements
- `docs/validation_plan.md` — ID'd validation methods/acceptance per subsystem
- `docs/operator_workflows.md` — operator-facing workflows
- `docs/testing_protocol.md` — pre-run / pre-commit test gates and `scripts/run_tests.sh` modes
- `docs/experiments_migration.md` — old concept → canonical experiment mapping

Subsystem traces, runbooks, and audits live alongside under `docs/`.
